The whole algorithm

h = first 52 bits of HMAC_SHA256(serverSeed, clientSeed + ":" + nonce)

if (h % 101 === 0)  carry = 1.00              // the house edge, 1 hole in 101
else                carry = floor(100 * 2^52 / (2^52 - h)) / 100

carry = min(carry, 10000)                     // hard cap, inside the derivation
yards = carry * 100

P(carry ≥ m) = (1 − 1/101) / m for every m, so the return to player is 99.0099% whether you lay up at 1.01x or hold for 10,000x. The math evidence file demonstrates that over 100,000,000 simulated holes.
